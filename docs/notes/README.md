# docs/notes — geçici çalışma notları

Burada **ömrü sınırlı** belgeler durur: PR açıklamaları, bir dalı hizalamak için
yazılmış tek seferlik talimatlar, bir karara nasıl varıldığını anlatan notlar.
Kayıt kalsın diye repo'ya alınır.

`docs/` kökündeki belgeler (`ARCHITECTURE.md`, `DATA.md`, `AGENTS.md`,
`API.md`, `MCP-TOOLS.md`) ise **kalıcı ve bakımı yapılan** dokümanlardır.

Kural: bir çelişki görürsen `docs/` kökündeki belge geçerlidir. Buradaki bir not
eskidiyse silinebilir — kaybı yoktur, git geçmişinde durur.

Her not, en üstünde tarihini ve neye ait olduğunu belirtir.
